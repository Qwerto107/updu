# 界面语言

支持英文（`en`）和简体中文（`zh-CN`）。页面右上角仅显示“中 / EN”分段开关，选择保存在当前浏览器。管理员在“设置 → 常规 → 默认语言”中保存实例默认值，保存后当前浏览器也采用此默认值。登录页和其他没有个人偏好的浏览器通过公开启动接口读取默认语言。

英文文案是翻译键，中文资源在 `zh-CN.json` 中。翻译缺失时保留英文，用户填写的名称、地址和业务数据保持原值。组件模板使用 `t`（可别名为 `translateUI`）获得响应式翻译；不要在模块顶层常量中缓存已翻译的结果。动态句子使用 `{count}` 等命名占位符，由第二个参数提供变量；不要拼接已翻译的句子或使用 `{@html}` 渲染译文。

新增语言：

1. 新建语言资源文件，例如 `ja.json`，保持英文键和占位符一致。
2. 在 `locales.ts` 注册语言代码、原生名称和资源；语言开关会自动增加选项，需要短标签时在 `language-select.svelte` 的 `shortLabels` 中补充。
3. 在 `internal/api/language.go` 注册允许保存的语言代码，避免任意输入成为默认语言。
4. 补充 `e2e/language.spec.ts` 中的注册表和回退验证，并检查长文案及移动端布局。

服务器日志、外部服务返回的诊断信息及尚无对应翻译的错误保留原文。
